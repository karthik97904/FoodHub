# FoodHub

FoodHub is a Zomato-like food ordering platform.

## Features

- User Registration
- User Login
- Restaurant Search
- Restaurant Listing
- Menu Management
- Cart
- Food Ordering
- Order Tracking
- Reviews

## Technologies

- React
- Spring Boot
- MySQL
- Git
- GitHub
